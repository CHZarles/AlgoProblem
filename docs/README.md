# Docs Assets

This folder stores README assets (hero image, screenshots, etc.).

Recommended structure:

- `docs/hero.svg` / `docs/hero.png`: README hero image
- `docs/shots/*.png`: feature screenshots (same width for consistency)

Notes:

- GitHub renders SVG/PNG directly in README via relative paths.
- You can replace the placeholder SVGs with real screenshots later (keep filenames to avoid updating links).
